# Learning Lab

个人编程练习与技术实验室。这里存放小型、可运行、可验证的练习项目，重点记录从概念理解到工程实现的过程。

## 目录

| 目录 | 内容 |
| --- | --- |
| [typescript/](./typescript/) | TypeScript、Node.js 与 Agent 工程练习 |
| [python/](./python/) | Python、RAG、记忆系统等练习 |
| [rust/](./rust/) | Rust 语言与系统编程练习 |
| [notes/](./notes/) | 学习记录、踩坑与阶段总结 |

## 练习项目规范

每个练习尽量包含：

1. **目标**：要解决什么具体问题。
2. **原理**：关键概念与设计思路。
3. **实现**：尽量保持小而完整，可以独立运行。
4. **验证**：提供测试或明确的运行结果。
5. **复盘**：记录学到了什么、还有什么限制。

## 约定

- 一个目录对应一个独立练习。
- 优先选择小而完整的例子，避免练习之间产生不必要的依赖。
- 重要的实现决策和限制写进各自的 README。
- 示例默认使用中文说明，代码命名遵循语言社区惯例。
